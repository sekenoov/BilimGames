# Путь Великой степи: инструкция для оператора

**Запуск:** двойной клик по `index.html` (Chrome или Safari) или главная страница BilimGames → Играть → История Казахстана → тема. Интернет не нужен.
Нажмите **F**, чтобы открыть игру на весь экран. Клавиша **L** меняет язык: қазақша / русский.

## Подготовка (1 минута)
1. Выберите тему: «Тюрки», «Ханство» или «Обе темы».
2. Выберите уровень: 6-7, 8-9 или 10-11 класс.
3. Выберите число команд (2-4) и впишите названия. Пустое поле возьмёт название-подсказку.
4. Укажите, сколько игроков в каждой команде: игра по кругу показывает, чья очередь говорить.
5. Выберите время игры (10/15/20 мин) и время на ответ (30/45/60 сек).

## Ход команды
1. Говорящий: «Асықты лақтырыңызшы!» / «Бросьте асык, пожалуйста!» → оператор жмёт **Space**.
2. Говорящий: «Екі қадам алға!» / «Вперёд на два шага!» → **Space**, фишка идёт.
3. На развилке команда говорит: «Солға, Суябқа!» / «Налево, в Суяб!» → **↑** (налево) или **↓** (направо).
4. Что бывает на клетке:
   - 🔵 **Вопрос**: дата, личность, термин или открытый вопрос. Учитель ставит **0-3** очка.
   - 🟡 **Историческое место**: вопрос про это место, тоже **0-3** очка.
   - 🟢 **Бонус**: удача (+очки, +шаги или бросок ещё раз) → **Space**.
   - 🔴 **Ловушка**: беда (джут, набег, ссора). Команда может спастись ответом.
     Ответили хорошо → **S** (штрафа нет), не справились → **Space** (штраф).

## Ответы
- **H** (держать): подсказка учителю. Для закрытых вопросов там правильный ответ.
- **A**: показать правильный ответ всему классу (после того как команда ответила).

## Горячие клавиши
Клавиши работают на любой раскладке: латинской, русской и казахской.

| Клавиша | Действие |
|---|---|
| Space | Бросить асык / идти / дальше |
| ↑ / ↓ | Выбор дороги на развилке |
| 0 1 2 3 | Очки за ответ |
| H (держать) | Подсказка учителю |
| A | Показать ответ классу |
| R | Другой вопрос |
| T | Пауза таймера ответа |
| S | Ловушка: команда спаслась |
| Backspace | Отменить последнее действие |
| P | Пауза общего времени |
| L | Сменить язык |
| M | Звук вкл/выкл |
| F | Полный экран |
| ? | Список клавиш |

## Конец игры
Игра заканчивается, когда **время вышло** или **команда дошла до финиша**.
После этого идёт **последний круг**, чтобы у всех было одинаковое число ходов. Побеждает команда с наибольшими очками.
В конце у всех один общий вопрос по теме: каждая команда отвечает одним предложением.

## Что меняется от игры к игре
- типы клеток раскладываются заново;
- вопросы, бонусы и ловушки идут в случайном порядке;
- короткие дороги быстрее, но на них больше ловушек.
