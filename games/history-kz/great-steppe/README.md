# Ұлы Дала жолы / Путь Великой степи

Игра-бродилка для урока истории Казахстана. Язык переключается между казахским и русским в любой момент.

![Путь Великой степи](assets/cover.png)

## Темы
- **Империя тюркских кочевников**: Тюркский каганат, Шёлковый путь, Караханиды, кыпчаки.
- **Казахское ханство**: Керей и Жанибек, ханы, бии, «Жеті жарғы», борьба с джунгарами.
- **Обе темы**: один путь от Алтая до Туркестана.

## Уровни
6-7 класс, 8-9 класс, 10-11 класс. У каждого уровня свой набор вопросов.

## Запуск
Откройте `index.html` двойным кликом или зайдите через главную страницу BilimGames.
Инструкция для оператора: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Как поменять вопросы
Весь контент лежит в двух файлах:
- `js/data-turks.js`: тема про тюрков;
- `js/data-khanate.js`: тема про Казахское ханство.

У каждого вопроса есть текст на двух языках (`ru` и `kz`) и уровни `lv`:
`1` = 6-7 класс, `2` = 8-9 класс, `3` = 10-11 класс.

```js
{ lv: [1, 2], cat: "date",
  ru: { q: "В каком году образовался Тюркский каганат?", a: "В 552 году." },
  kz: { q: "Түрік қағанаты қай жылы құрылды?", a: "552 жылы." } }
```

- `a` это правильный ответ. Его видит учитель (клавиша H), классу показывает клавиша A.
- Для открытых вопросов вместо `a` пишется `hint` (подсказка учителю) и `say` (начало ответа для учеников).

Тексты кнопок и меню лежат в `js/i18n.js`.
