# Tech Trail — инструкция для оператора

**Запуск:** двойной клик по `index.html` (Chrome или Safari). Интернет не нужен.
Нажмите **F**, чтобы открыть игру на весь экран.

## Подготовка (1 минута)
1. Выберите число команд (2–4).
2. Впишите названия команд. Если оставить поле пустым, возьмётся название-подсказка.
3. Укажите, сколько игроков в каждой команде: игра по кругу показывает, чья очередь говорить (Speaker 1, 2, 3…).
4. Выберите время игры (10/15/20 мин) и время на ответ (30/45/60 сек).

## Ход команды
1. Говорящий: *"Roll the dice, please!"* → оператор жмёт **Space**.
2. Говорящий: *"Move two steps!"* → **Space**, фишка идёт.
3. На развилке команда говорит: *"Turn left to the School!"* → **↑** (налево) или **↓** (направо).
4. Что случается на клетке, куда пришла фишка:
   - 🔵 **Question**: команда отвечает вслух, учитель ставит **0–3** очка.
   - 🟡 **Place challenge**: задание локации, тоже **0–3** очка.
   - 🟢 **Bonus**: польза технологий (+очки, +шаги или бросок ещё раз) → **Space**.
   - 🔴 **Trap**: вред технологий. Команда может «спастись»: ответить на вопрос.
     Ответили хорошо → **S** (штрафа нет), не справились → **Space** (штраф).

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| Space | Бросить кубик / идти / продолжить |
| ↑ / ↓ | Выбор дороги на развилке |
| 0 1 2 3 | Очки за ответ |
| H (удерживать) | Подсказка учителю: примеры ответов |
| R | Другой вопрос (если слишком сложный) |
| T | Пауза таймера ответа |
| Backspace | Отменить последнее действие |
| P | Пауза общего времени игры |
| M | Звук вкл/выкл |
| F | Полный экран |
| ? | Список клавиш |

## Конец игры
Игра заканчивается в двух случаях:
- **время вышло**;
- **какая-то команда дошла до финиша**.

После этого объявляется **Final round**: доигрывается текущий круг, чтобы у всех команд было одинаковое число ходов. Побеждает команда с наибольшими очками.
Кнопка **Play again** запускает новую партию с теми же командами. Клетки перемешиваются, поэтому каждая игра получается разной.

## Что меняется от игры к игре
- типы клеток (вопрос, бонус, ловушка) раскладываются заново;
- 40 общих вопросов, 21 задание для локаций, 10 бонусов, 11 ловушек, всё в случайном порядке;
- короткие дороги (Gaming Club, Mall) быстрее, но на них больше ловушек.
