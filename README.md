# BilimGames

Платформа игр для урока на общем экране. Команды отвечают, учитель ставит очки, оператор ведёт игру с клавиатуры.

На главной странице нажмите **Играть**, выберите предмет, потом тему.

| Предмет | Игра | Язык |
|---|---|---|
| История Казахстана | [Ұлы Дала жолы / Путь Великой степи](history-kz/) | казахский и русский |
| Английский язык | [Tech Trail](english/tech-trail/) | английский (A2-B1) |

## Играть онлайн
**https://sekenoov.github.io/BilimGames/**

## Запуск без интернета
Скачайте репозиторий и откройте `index.html` двойным кликом. Сервер и интернет не нужны.

## Структура
```
index.html            главная: Играть → предмет → тема
hub/                  стили и логика главной
history-kz/           игра по истории Казахстана (RU/KZ)
english/tech-trail/   игра по английскому
```

## Как добавить предмет или тему
1. Положите игру в свою папку, например `math/fractions/`.
2. Допишите её в список `SUBJECTS` в начале файла `hub/hub.js`.
