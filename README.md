# BilimGames

Платформа игр для урока на общем экране. Команды отвечают, учитель ставит очки, оператор ведёт игру с клавиатуры.

На главной странице нажмите **Играть**, выберите предмет, потом тему.

| Предмет | Игра | Язык |
|---|---|---|
| История Казахстана | [Ұлы Дала жолы / Путь Великой степи](games/history-kz/great-steppe/) | казахский и русский |
| Английский язык | [Tech Trail](games/english/tech-trail/) | английский (A2-B1) |

## Играть онлайн
**https://sekenoov.github.io/BilimGames/**

## Запуск без интернета
Скачайте репозиторий и откройте `index.html` двойным кликом. Сервер и интернет не нужны.

## Структура
```
index.html                        главная: Играть → предмет → тема
hub/                              стили и логика главной
games/
├── history-kz/
│   └── great-steppe/             Ұлы Дала жолы: история Казахстана (RU/KZ)
└── english/
    └── tech-trail/               Tech Trail: английский
```
Каждая игра живёт в своей папке и работает сама по себе: её можно открыть двойным кликом по её `index.html`.

## Как добавить предмет или тему
1. Положите игру в папку предмета: `games/<предмет>/<игра>/`, например `games/math/fractions/`.
2. Допишите её в список `SUBJECTS` в начале файла `hub/hub.js`.
