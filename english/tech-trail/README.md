# Tech Trail

Офлайн веб-игра-бродилка для урока английского (A2–B1) на тему **пользы и вреда технологий**.
Игра идёт на общем экране: команды говорят по-английски, а оператор за ноутбуком выполняет их команды.

![Tech Trail](assets/cover.png)

## Играть онлайн
**https://sekenoov.github.io/tech-trail-english-game/**

## Запуск без интернета
Скачайте репозиторий и откройте `index.html` двойным кликом. Интернет и сервер не нужны.

## Как играть
- 2–4 команды со своими названиями, игра показывает, чья очередь говорить.
- Кубик 1–3, карта с развилками: длинные «безопасные» дороги и короткие рискованные.
- Клетки: **вопросы** и **задания локаций** (0–3 очка), **бонусы** (польза технологий), **ловушки** (вред технологий, от них можно «спастись» ответом).
- Типы клеток и вопросы перемешиваются при каждом запуске.
- Побеждает команда с наибольшими очками, когда время вышло или кто-то дошёл до финиша (доигрывается текущий круг).

Подробная инструкция для оператора и горячие клавиши: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Структура
```
index.html     экраны: настройка, игра, итоги
css/style.css  стили
js/data.js     весь контент: вопросы, задания, бонусы, ловушки
js/game.js     игровая логика
js/sound.js    звуки (Web Audio, без файлов)
assets/        иллюстрации локаций
```
Чтобы поменять вопросы, отредактируйте `js/data.js`.
